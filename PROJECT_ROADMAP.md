# Nikoo Homes 9 — Modular Build Plan

Each module is completed mobile first, checked at 390 px, expanded to tablet/desktop,
animated, and then frozen before moving forward.

## Module 1 — Foundation and design system (complete)

- Next.js App Router and TypeScript configuration
- Mobile-first design tokens, typography and spacing
- `next/font` display/body font pairing
- Responsive container, button and media-placeholder primitives
- Metadata, viewport and reduced-motion baseline
- Temporary foundation preview page

Acceptance: project opens, base styling is responsive, no horizontal overflow, shared
components are ready for sections.

## Module 2 — Conversion header and hero (complete; regulatory verification pending)

- Mobile header, menu and desktop navigation
- Mobile/desktop hero composition
- Project headline, project fact chips and lead entry CTA
- First lead form/modal
- Hero reveal sequence and sticky mobile CTA

Required from content owner: logo, headline, supporting copy, fact chips and CTA labels.

## Module 10 — Integration and final QA (demo-mode source complete)

- CRM/API connection and event tracking
- Form error/success flows

- Responsive checks at 360, 390, 430, 768, 1024 and 1440 px
- Keyboard, reduced-motion and performance review
- Production build and deployment

Required: CRM endpoint, analytics IDs, production domain and final approved content/media.

## Working rule for every module

1. Receive approved content and assets.
2. Build the mobile hierarchy and interaction.
3. Review at 390 px.
4. Expand to tablet and desktop.
5. Add restrained animation and accessibility behavior.
6. Verify and freeze the module.
